# r25 — 중복 정리와 통합 설명서

- 메인 화면의 반복 자료 관리 버튼을 상단 자료 목록/휴지통으로 통일했습니다.
- 별도 작업 팝업의 자료 관리 바로가기는 작업 편의를 위해 유지합니다.
- 맵 준비 창에서 메인 모델링 열과 겹치는 PDF·스캔·지형 메뉴를 제거했습니다. 해당 창은 대지와 시작 위치 설정에 집중합니다.
- 과거 최신 안내가 누적된 README를 현재 안내 하나로 교체했습니다. 버전별 README는 이력으로 보존합니다.
- 과거 버전별 업데이트 구현의 복제 코드를 제거하고 현재 Apply-R25.ps1을 호출하는 호환 진입점으로 통일했습니다.
- 통합 사용 설명서를 Markdown 및 인쇄 가능한 오프라인 HTML로 추가하고 상단에 사용 설명서 버튼을 넣었습니다.
- 설치 안내에서 PDF·지형의 추가 모듈이 필요 없다고 남아 있던 문구와 옛 시험장 메뉴 이름을 수정했습니다.

기능 설명은 현재 코드 기준입니다. 원시 점군/사진의 자동 복원, RWP 해독, 자동 피벗 보정, 임의 스캔 유리 파괴는 구현 완료로 설명하지 않습니다.
사용자 파일의 중복 여부를 추정해 자동 삭제하지 않습니다.

검증: Python 테스트 154개, Python 구문 검사 및 배포 파일 체크섬 확인. 실제 Windows GUI/Unreal 빌드는 미검증입니다.
